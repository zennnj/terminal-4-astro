## class vs. struct
**class** defaults to **private**
**struct** defaults to **public**
***只有这一点点区别！首选class.只有在类及其简单时使用struct***

```c++
struct A{
    int i; //this is public
public:
    A();
};

class B{
    int i; //this is private
public:
    B();
};
```
